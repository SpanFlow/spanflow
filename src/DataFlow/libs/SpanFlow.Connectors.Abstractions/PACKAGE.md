# SpanFlow.Connectors.Abstractions

The small types that every SpanFlow connector library shares: `ConnectionCheck` (the result of a quick check that
a connection is reachable and valid) and `DeliveryResult`. You normally get this package through
[SpanFlow.Connectors.Files](https://www.nuget.org/packages/SpanFlow.Connectors.Files) rather than referencing it
yourself.

Part of [SpanFlow](https://github.com/SpanFlow/spanflow). Targets .NET 8, 9 and 10. MIT licensed.
