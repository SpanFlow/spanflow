  1. Drag nodes in from the left.
  2. Join them: the right-hand dot to the next node.
  3. Press Run flow. Each node's answer is on the node, and in full here.
  4. Open C# code to take it into your own app.

Each node passes its answer to the next as input. Every earlier answer is also in vars, by node name. Use them in {{ }} placeholders.

      Fair use
      
      
      
      
      
      
      Each node is one call to this server, counted against its library's limits. The same calls work from a script: POST /api/expressions/evaluate, /api/http/send, /api/files/convert and /api/database/query. Refusals are { "error", "reason" } with Retry-After and RateLimit-* headers.
