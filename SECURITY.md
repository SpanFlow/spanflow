# Security policy

## Reporting a vulnerability

Please report security problems privately through GitHub:
**Security > Report a vulnerability** on this repository
([private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)).

Do not open a public issue or pull request for a vulnerability.

Include the version, the affected component (Platform, DataFlow, UFMapping, admin console), steps to reproduce
and the impact you expect. You will get an acknowledgement within a few working days, and a fix or a plan
before any public disclosure.

## Supported versions

Security fixes are made for the latest release. Upgrade to it before reporting, if you can.
